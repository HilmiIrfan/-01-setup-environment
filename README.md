### Praktikum 2
1. Pada Langkah ke-2, setelah membuat proyek baru menggunakan Next.js, terdapat beberapa istilah yang muncul. Jelaskan istilah tersebut, TypeScript, ESLint, Tailwind CSS, App Router, Import alias, App router, dan Turbopack!

    a. TypeScript: versi "super" dari JavaScript yang menambahkan tipe data statis.
    
    b. ESLint: tool untuk mendeteksi dan memperbaiki kesalahan penulisan kode (linting) di JavaScript atau TypeScript.

    c. Tailwind CSS: framework CSS utility-first, dimana user dapat menambahkan class pada elemen HTML untuk mengatur styling tanpa harus menulis CSS manual.

    d. App Router: sistem routing Next.js berbasis folder app/.

    e. Import Alias: cara memberi nama pendek atau jalur khusus untuk import file/module agar lebih rapi.

    f. Turbopack: bundler pengganti Webpack yang dikembangkan oleh tim Vercel untuk Next.js.

2. Apa saja kegunaan folder dan file yang ada pada struktur proyek React yang tampil pada gambar pada tahap percobaan ke-3!
    - .next: menyimpan hasil build proyek, menjalankan aplikasi, cache performa.
    - node_modules: folder tempat npm menyimpan semua library/dependency yang dipakai.
    - public: menyimpan file statis seperti gambar
    - src\app: folder utama untuk routing dan struktur halaman
    - .gitignore: berisi daftar file/folder yang tidak perlu dimasukkan ke Git.
    - eslint.config.mjs: file konfigurasi ESLint dalam format ES Module (ESM).
    - next-env.d.ts: file TypeScript deklarasi global yang dibutuhkan oleh Next.js agar proyek TypeScript dapat berjalan dengan benar dan mengenali fitur-fitur Next.js.
    - next.config.ts: file konfigurasi untuk mengatur redirect, image optimization, dll pada Next.js.
    - package-lock.json: manajemen proyek React atau proyek Node.js secara umum.
    - package.json: file utama untuk menyimpan nama proyek, script, dependency.
    - postcss.config.mjs: mengatur PostCSS, yaitu sebuah tool untuk memproses CSS dengan berbagai plugin sebelum akhirnya CSS dikirim ke browser.
    - README.md: file untuk dokumentasi proyek seperti cara install, perintah penting, dll.
    - tailwind.config.ts: mengatur tema warna, breakpoints, plugins, dsb.
    - tsconfig.json: berisi pengaturan seperti alias @/, strict mode, dan compiler options TypeScript.
